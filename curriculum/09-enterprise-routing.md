# M09 — Enterprise routing and resilience

**Status:** curriculum specification; not a claim that lessons have been completed.
**Prerequisites:** M04, M08

## Topic scope
- **M09.01** — OSPF neighbors, areas, link state, and path selection
- **M09.02** — BGP sessions, announcements, attributes, and policy
- **M09.03** — Route redistribution, filtering, and loop prevention
- **M09.04** — Summarization, multi-homing, and failure containment
- **M09.05** — IPv6 routing and dual-stack migration
- **M09.06** — Gateway redundancy, BFD, and convergence trade-offs
- **M09.07** — Multicast foundations, group membership, and distribution
- **M09.08** — Routing security, route validation, and change verification

## Theory and mechanisms
Explain route advertisement versus forwarding and validate a policy in a controlled topology.

## Numericals and algorithmic work
Trace route preference and path changes under failures; reason about convergence and address-summary ranges.

## Practical route
Use an approved emulator or routing containers later; save versioned configurations and pre/post checks.

## Senior/principal application
Defend a multi-site routing design and its failure/recovery behavior.

## Evidence to collect
Ask for a mechanism explanation and an unfamiliar application. Add calculations, state traces, experiments, troubleshooting, and a design rationale when applicable. Record what was attempted, assistance, observations, and remaining gaps. Untested dimensions stay unassessed; watching a video or reading a generated note is not mastery.

## Lesson expansion rule
Prepare detailed lessons only as needed. Record stable topic IDs in notes and evidence. Use source dates and version-specific documentation for implementations. A learner may request a useful specialization without completing every unrelated branch.

## Sources to consult
CISCO-CCNP, JUNIPER-TRACKS, RFC1812 in [the source register](../references/SOURCES.md). These are starting references, not proof that each listed topic is fully covered by a single source. Retrieve topic-specific standards and vendor documentation before advanced teaching.
