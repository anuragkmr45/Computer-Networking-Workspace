# Practice

Use [concept and tracing questions](QUESTIONS.md) or [numerical problems](NUMERICALS.md). Solutions are separate in [ANSWERS](ANSWERS.md) and [NUMERICAL_SOLUTIONS](NUMERICAL_SOLUTIONS.md). Do not open them before an attempt in retrieval mode.

These are original educational exercises, not copied exam questions. Difficulty should follow evidence. Ask one question at a meaningful pause unless the learner asks for a set. Record help used, not only correctness. Lab and design practice live under labs and capstones.

For numerical work: state model, known values, units, formula, substitution, result, sanity check, and limitations. For protocol work: draw devices, state, message fields, and sequence. For troubleshooting: separate prediction, observation, and inference.
