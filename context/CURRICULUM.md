# Curriculum pointer

The authoritative syllabus is [curriculum/README.md](../curriculum/README.md), with one scope file per module and machine-readable topic IDs in [catalog.json](../curriculum/catalog.json).

The syllabus records intended learning scope, not completed lessons or proven competence. Study from fundamentals, accelerate through demonstrated strengths, and use advanced branches when prerequisites and work needs justify them. Do not force every certification into a single linear exam-preparation sequence.
