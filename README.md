# Computer Networking Mastery
## A persistent tutor workspace for a senior software engineer growing toward principal-level work

**Version 1.0 · Created October 29, 2026 · Learning timezone: Asia/Kolkata**

Start with [START_HERE.md](START_HERE.md). Your personal checkpoint is already loaded; no repeat onboarding or prerequisite quiz is required.

### What you receive
- A 16-module engineering syllabus with explicit theory, numericals, practical work, troubleshooting, and design outcomes.
- Your profile, learning evidence, preferences, and exact next lesson, migrated from this conversation and your earlier AI-engineering workspace.
- Six repository-local tutor skills, plus compact `AGENTS.md` instructions.
- Written starter notes on packet delivery, subnetting, ARP, and switching; separate fast-recall notes and answer keys.
- Original practice questions, numerical solutions, local lab guides, a loopback TCP demonstration, and an offline interactive ARP walkthrough.
- Versioned progress and review records, controlled refinement rules, source references, and a certification alignment register.
- Standard-library Python utilities and tests. No paid service, API key, external dependency, Notion integration, or installer is included.

### What this is not
This is an operational learning framework with useful starter content, **not a fully written textbook for every advanced topic or a complete exam-preparation course**. The syllabus is broad; most later lessons are generated, verified, and saved as we study them. Certification mappings are domain-level planning maps, not audited objective-by-objective coverage or guarantees of passing.

### Daily use
Say `continue learning`, `recall ARP`, `practice subnetting`, `show the packet flow`, `go deeper`, `lab mode`, `feedback: fewer quizzes`, or `checkpoint`. These are natural-language requests, not installed terminal commands.

The tutor should read the saved state, teach a cohesive unit, check understanding at a useful stopping point, and save meaningful progress when it has write access. It should not turn each definition into another compulsory quiz.

### Persistence, not magic memory
The saved files are the continuity mechanism. A new agent must read them. Unsaved conversations are not automatically imported. Refinement occurs during active, authorized sessions; nothing here runs in the background. These files do not train the underlying model.

Local files do not guarantee local-only model processing or laptop-only chat access. No account connection or synchronization has been enabled by this ZIP. Keep files outside a cloud-synced folder when local file storage is your preference, and review your client's privacy and permission settings separately.
